# Catalyst Physics

Catalyst Physics brings Smalltalk-native rigid-body physics to Bloc.

Elements can move under forces, collide with one another, bounce, slide, sleep, and be connected by joints and constraints. Instead of treating position as something an application must calculate, Physics lets position emerge from the relationships between elements.

Being an in-image simulation, the element count is limited. That said, Physics is now closely aligned with Box2D 3.1.1. Box2D gives us a mature and well-understood simulation model, while preparing Physics for deeper Box2D integration in the future.
